О шрифте

Fira Code — это моноширинный гротеск, используемый для написания и чтения кода

Примечательно, что за его основу был взят шрифт Fira Mono, который уже в 2014 году был дополнен программируемыми лигатурами

Начертания

Помимо привычных начертаний, Fira Code содержит начертание Retina, предназначенное для экранов Apple Retina, что делает шрифт доступным для всех ПО.

Глифы и лигатуры

Адаптивность Fira Code к средам программирования выражается в глифах и лигатурах, представляющих собой совмещенные знаки, которые образуют целостный и приятный глазу оператор.

Стили шрифта

Несмотря на то, что Fira Code — это гротеск, его символы содержат своеобразные засечки, которые и делают шрифт моноширинным
